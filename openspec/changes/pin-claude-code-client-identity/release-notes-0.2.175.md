发布 v0.2.175：固定 Claude Code 版本并统一客户端隐私处理

## 更新内容

- Anthropic OAuth / SetupToken 出口固定为 Claude Code 2.1.299，同步 SDK、运行时、请求头和 billing 归因格式；管理端版本设置、环境变量和自动版本检查均不能单独升级出口版本。
- 按上游账号维护设备标识，重建客户端 metadata 和会话标识，移除扩展 metadata；每次构造请求生成新的请求 ID。
- 在最终出口统一处理自动环境信息，覆盖 messages、count_tokens、Chat Completions / Responses 兼容入口及重新构造请求的重试。
- 已确认的自动日期、MCP 日期解析和日程模板统一使用 UTC，清除语言偏好请求头、详细系统版本和可选逐轮计时字段。
- 保留普通对话、用户回复语言、工具参数与结果以及 thinking/signature；修正普通引用被日期清洗误改的问题。
- 新增 v2 事件批量端点的本地丢弃处理；后台 Metadata 透传固定关闭，自动日期归一化固定开启。

## 升级说明

- 无数据库迁移。以上固定身份及隐私规则针对 Anthropic OAuth / SetupToken；API-key passthrough 和其他供应商保持原行为。
- 自动日期解析与日程改按 UTC 解释，相对时间和日程语义会随之变化。工作目录、平台和 Shell 继续保留真实值以支持工具执行，路径仍可能包含用户名。
- 原有自动版本检查开关仍控制联网检查，但检查结果不改变固定出口版本。接入客户端的最低／最高版本限制仍然有效。
- 处理范围限于到达网关的请求和已确认的自动模板；桌面端独立遥测不经过网关时无法拦截。本版本不承诺任意客户端完全一致或避免账号限制。

## 验证

- 已完成相关后端包回归、隐私专项与 race、go vet、增量 lint，以及前端类型、定向 ESLint 和 i18n 检查。
- 临时隐私测试覆盖 48 组出口组合、兼容入口、重复会话头、缓存降级及正文保留，验证后已清理。
- 本地前端完整构建及包含前端资源的后端构建通过，生成的程序版本输出为 0.2.175。
- 推送版本标签后由 GitHub Actions 构建和发布安装包、镜像；没有使用真实上游账号进行模型调用验证。
