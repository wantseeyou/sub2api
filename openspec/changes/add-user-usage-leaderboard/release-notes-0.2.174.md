发布 v0.2.174：新增普通用户用量排行榜

## 更新内容

- 通用设置的“自定义菜单页面”下新增“展示排行榜”开关，默认关闭。
- 开启后，普通用户可从“兑换”下方进入“用量排行榜”，管理员不参与排名。
- 支持 Top50／Top100，以及今日、昨天、7 天、30 天；统一使用北京时间自然日，7 天和 30 天包含今天。
- 默认按总 Token 降序排名，支持切换请求数、输入、输出、缓存 Token 和实际费用排序；汇总全部匹配记录后截取榜单，同分按用户 ID 保持稳定顺序。
- 有昵称时显示昵称，无昵称时显示完整邮箱；仅返回用户侧所需的用量和实际费用。
- 开关关闭时同时隐藏入口、阻止页面访问并关闭查询接口；快速切换筛选时取消旧请求，避免显示过期结果。

## 升级说明

- 无数据库迁移，旧配置默认关闭排行榜；更新其他设置时不会误改此开关。
- 统计口径沿用管理端用户排行，基于现存使用记录；清理记录会影响对应日期的榜单。
- 推送版本标签后，由 GitHub Actions 自动构建安装包和镜像并发布；本地构建用于验证。
