# 0.2.192 设置与分组用量优化、临期重置卡保底使用

## 界面优化

- 系统设置顶部页签支持横向滚动，名称完整显示，兼容桌面和窄屏。
- 分组查看的账号用量采用账号管理同款进度条，显示额度窗口、重置倒计时、重置卡次数及最早到期时间。
- 补充分组账号的实际调度状态、管理员调度开关、限制截止时间和状态徽章。

## 重置卡自动化

- 在“系统设置 → Codex 管理”新增“到期前 N 分钟无条件使用重置卡”，默认关闭，默认提前 10 分钟，可设置 1–1440 分钟。
- 开启后，临期卡不受额度阈值限制，用量为 0% 也可使用；仍保留人工停用、账号到期、限流及其他故障保护。
- 原“到期前 N 天使用”策略保持兼容，仍要求达到额度停调阈值并暂停调度，无需用到 100%。
- 修复多实例任务迟到回写覆盖新卡状态的问题；请求超时只重试同一卡，确认成功后再处理下一张。

## 升级与数据兼容

- 从 0.2.191 升级没有新增数据库迁移，无需回填数据；新开关默认关闭，原有配置继续生效。
- 从更早版本升级仍会按现有流程执行此前版本的迁移，包括分组只读授权表。
- 分组查看继续使用字段白名单，仅展示授权范围内的缓存快照，不暴露凭据、卡片 ID 或其他分组数据。
