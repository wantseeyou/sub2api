# 0.2.191 分组只读查看

## 新增功能

- 管理员可在“用户管理 → 分组查看授权”中为站内用户配置一个或多个可查看分组。
- 获授权用户可查看账号概况、人员用量和使用明细，支持多组与时间筛选、排序、分页、汇总和趋势图。
- 共享上游账号显示已有额度快照，并明确区分共享额度与组内用量。

## 权限与兼容性

- 每次请求重新校验授权；列表、统计和筛选候选均限定在授权范围，撤权后新请求立即生效。
- 使用历史按日志记录的分组归属统计；Key 删除或调组不迁移历史。
- 响应隐藏凭据、上游成本、内部配置及其他分组信息；不改变原有个人功能、模型调用资格和计费规则。
- 分组查看的分页选项限定在接口允许的 100 条以内，兼容全局配置中更大的分页选项。

## 升级说明

- 正常启动新版服务时自动执行新增迁移 `249_user_group_view_grants.sql`，无需回填现有用户。
- 现有用户默认没有分组查看权限，由管理员显式授权；公司间需要隔离时请使用不同分组。
- 回滚应用可保留新授权表，无需修改历史用量。

## 验证

- 后端完整测试、静态检查和构建通过，前端相关既有测试与生产构建通过。
- 隔离数据库已验证迁移、跨组隔离、历史归属、字段白名单和并发授权。
- 使用 `gpt-6-astra` 子代理完成独立审查，已修复发现的分页兼容性问题。
