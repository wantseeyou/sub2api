# 0.2.193 后台角色与树状权限管理

## 角色与权限

- 保留管理员、普通用户，新增可自定义的后台角色；支持角色创建、编辑、复制、启停和用户分配。
- 新增 154 项树状权限，按模块及具体操作授权，支持搜索、模块全选和半选；页面、按钮、接口及共享接口字段统一校验权限。
- 预置“助理”角色，默认可查看常规业务数据、重新授权上游账号以及启用和停用账号；导出、删除、其他写入、主动探测及敏感日志和提示词内容需另行授权。
- 仅内置管理员的登录会话可管理和分配角色；角色权限和停用状态在后续请求重新读取。
- 普通角色查询剥离账号凭据、用户 API Key 原文和代理密码；账号重新授权在服务端完成凭据交换及保存。

## 界面调整

- 移除旧分组查看页面、接口和授权入口，保留业务分组及模型调用的分组使用权限。
- 用户管理、账号管理、IP 管理默认每页显示 50 条，仍可手动调整。

## 升级与数据兼容

- 启动时执行 `250_admin_roles.sql`，新增角色表、用户角色关联及索引，并创建助理模板；已有用户不会自动分配后台角色。
- 旧分组查看者不自动迁移，管理员可按实际职责重新分配角色；历史授权表和历史迁移保留。
- 回退应用时可保留新增表和字段；旧版不识别新后台角色，但恢复的旧分组查看入口可能继续使用历史授权。

## 验证

- 相关后端单元测试、服务端构建、前端回归测试、类型检查、ESLint、翻译检查及生产构建通过。
- 隔离 PostgreSQL 验证迁移重复执行、角色关联与停用、删除约束及并发写入保护。
- 完成越权接口与字段、敏感输出、配置逐键更新及账号重授权并发的定向验证。
- 未使用真实第三方账号完成 OAuth 授权交换验收。
