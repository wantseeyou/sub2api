发布 v0.2.172：优化 Codex 转发并新增模型一致性检测

## 更新内容

- 新增 ChatGPT Codex Responses HTTP 出站压缩，保持原始请求和重试输入可重读。
- 修复 Codex 线程、回合与窗口信息保真，以及原生 WebSocket 重连时握手仍沿用首回合信息的问题。
- 完善回合路由状态的来源校验、流式保活和错误终态处理；请求发送后执行状态不明时不再透明重放。
- 账号高级设置新增 HTTP 入站转 WebSocket 上游开关，客户端仍按原请求接收 SSE 或 JSON，透传请求保留大整数精度。
- 新增脱敏链路诊断信息，便于确认实际传输、压缩、失败阶段和回退原因。
- 管理员账号菜单新增模型一致性检测，支持手动选择模型、取消任务及查看最近结果；已完成模型的结果和用量不会因后续模型超时或取消而丢失。

## 升级说明

- HTTP→WS 和新的线程隔离开关均默认关闭；强制 HTTP、compact 及插件传输限制继续生效。
- 启用线程隔离后请新建会话。续链来源校验使用本实例的有界缓存，实例重启、切换或缓存淘汰后可能需要新建会话；多实例部署需评估会话路由。
- 模型一致性检测只支持普通 OpenAI OAuth/SetupToken 账号，每次最多选择 8 个模型，每模型最多 3 份样本。检测会消耗上游额度，结果仅作为经验线索，不代表模型身份认证或能力评分。
- 本次无需手动数据库迁移；检测不会自动改变账号调度状态。
