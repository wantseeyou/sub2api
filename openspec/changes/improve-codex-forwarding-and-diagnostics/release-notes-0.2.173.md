发布 v0.2.173：完善 Codex WebSocket 转发、连接轮换与诊断

## 更新内容

- 账号批量编辑新增“HTTP 请求使用 WS 上游”，支持与 WS mode 一起设置。
- 普通 HTTP、HTTP 透传和原生 ctx_pool 支持同连接增量输入；校验调用方、线程、窗口和完整历史，只保留有界摘要。
- 自动续链锚点被明确拒绝时，最多恢复一次完整请求；请求已执行或执行状态不明时不自动重放。
- 大请求默认按 15 MiB 阈值在发送前改走 HTTP，同时检查实际编码大小；显式续链超限时明确拒绝，避免丢失上下文。
- WS 池连接到 55 分钟后在安全时机轮换；原生 ctx_pool 在历史完整时恢复上下文，历史或工具调用不完整时明确提示。
- 修复普通 OpenAI OAuth/SetupToken 的网页搜索能力兼容：文字与图片混合声明保留文字搜索，纯图片搜索明确提示不支持；现有 OAuth 模型清单与缓存标识同步更新。
- 模型一致性检测区分鉴权、限流、模型不可用、请求参数及上游服务错误；管理员 WS 诊断保留执行阶段、失败原因和关闭码，真实上游状态与网关合成状态分开记录。

## 升级说明

- 本次没有数据库迁移，已有账号配置兼容；HTTP→WS 开关仍默认关闭。
- 大请求分流复用 `gateway.openai_ws.http_bridge_enabled` 和 `http_bridge_threshold_bytes`，不新增配置项。15 MiB 是本项目的分流阈值，不代表上游公布的大小上限。
- `store=false` 续链所需连接失效或到龄时，需要客户端提供完整上下文并移除 `previous_response_id` 后重建；持久化的 API Key 响应续链保持兼容。
- 单次执行跨越上游 60 分钟硬限制仍可能失败；原生透明 passthrough 不自动重建完整会话。
- 网页搜索兼容调整不影响 API Key、Agent Identity、图片输入或图片生成。
- 缺少可信参考指纹的模型继续显示“无法判定”，本次不新增替代指纹，也不保证消除上游过载或网络中断。

## 发布方式

- 推送版本标签后，由 GitHub Actions 自动构建安装包和镜像并发布；本地构建仅用于验证。
