# 后台角色与权限管理

状态：已实现并完成本地验证，随 v0.2.193 发布；生产数据库迁移在升级启动时执行。

## 身份与分配

- 保留 `admin`、`user` 两类内置身份；普通用户不进入管理后台，管理员具有完整后台权限。
- 用户可关联一个自定义后台角色。助理是可修改的预设角色，不按名称判断权限。
- 只有内置管理员的登录会话可以管理和分配自定义角色；角色管理与已有管理员 API Key 授权分开。
- 角色支持创建、编辑、复制、启停；仍有未删除用户关联时不能删除。
- 角色权限或状态在下一次后台请求重新读取，不把权限永久写入 JWT。

## 权限树

权限目录定义于 `backend/internal/pkg/adminaccess/role_catalog.go`，共 154 项权限，按业务模块分组，授权到具体动作，支持搜索、模块全选及半选。未登记的接口默认拒绝。常规查看、敏感内容、编辑、导入、导出、删除及执行操作分别授权；HTTP 方法不决定是否为只读。

| 模块 | 主要动作 |
| --- | --- |
| 经营报表、用量 | 查看、聚合维护 |
| 上游账号 | 查看、重新授权、启停、基本资料、调度、网络、模型、分组、凭证、高级配置、主动探测、恢复、导入导出、删除 |
| 站内用户 | 查看、创建编辑删除、余额、平台额度、批量操作、身份绑定 |
| 分组、渠道、代理、API Key | 查看及各自的维护动作 |
| 订阅、支付、套餐、返利 | 查看、分配、调整、退款、取消、补发及其他维护 |
| 公告、优惠码、卡密、属性 | 查看、新增、编辑、删除及导出 |
| 运维、风控、审计、提示词 | 常规状态、敏感事件内容及管理动作 |
| 系统设置、插件、备份、数据管理 | 查看、配置、执行、导出、删除 |

菜单和按钮按同一权限控制；后端独立检查接口和共享接口的字段。操作权限一般需搭配相应查看权限，辅助模块未授权时不自动开放。

## 助理初始权限

允许全部常规业务查看，以及 `accounts.reauthorize`、`accounts.status`。默认不允许其他写入、主动探测、导出、删除、敏感日志和提示词内容；管理员可按需要编辑该模板，包括显式授予导出权限。以后新增的权限不会自动加入助理。

普通账号列表、详情、用户 Key、代理及配置响应剥离凭证原文。账号完整数据导出独立校验导出权限，并沿用现有二次验证。角色管理和分配沿用已配置的二次验证策略。

## 共享接口边界

- `PUT /accounts/:id` 与批量更新逐字段检查启停、调度、凭证、网络、模型、分组及高级配置权限；不接受大小写别名或未知字段借路修改。
- 自定义角色重新授权使用账号专属的授权 URL 和交换入口。平台、代理、客户端及项目配置取自目标账号；交换、落库在服务端完成，响应不含 token。
- 授权交换在数据库事务外完成，落库时短事务锁定账号，检查配置是否变化，并合并最新认证字段，保留模型、网络和调度配置。
- 只有常规查看权限时，用量接口读取已有快照；可能发送探针、刷新认证或恢复状态的主动查询另行授权。
- 自定义角色不能通过用户管理或 API Key 管理修改后台成员；单项写入在事务中锁定用户并复核身份，批量写入在最终 SQL 中限制目标身份。
- 自定义角色通用编辑只提交获授权且实际改动的字段；`credentials`、`extra` 采用逐键补丁，非认证配置的显式 `null` 表示删除，认证字段禁止以空值删除。
- 通用账号编辑先锁定再读取，避免回写旧凭证；调度快照在事务提交成功后刷新。
- 普通用户和后台角色仍可维护自己的个人资料、密码及二次验证；仅后台模式下按同样边界放行。

## 数据与迁移

`250_admin_roles.sql` 新增角色表、用户可空角色外键、索引及助理预设。用户基础 `role` 字段保留；管理员不能关联自定义角色。角色列表批量统计成员，用户查询预加载角色，不逐用户访问数据库。

旧分组查看的页面、接口、授权入口和服务接线移除；业务分组与模型调用权限保持原有语义。旧授权表和历史迁移保留，旧查看者不会自动升级为后台角色，由管理员另行分配。

应用回滚可保留新增表和字段，旧程序忽略自定义角色关联，相关用户不再获得新后台访问能力；旧版本恢复的旧分组入口仍可能使用历史授权。若最终删除新增数据库对象，需先回退应用、备份角色数据，再移除用户外键和新增表。

## 验证目标
