# 按角色分配后台功能与操作权限

普通用户、管理员保留为内置身份，其他后台身份由自定义角色承载权限，再将角色分配给站内用户；助理作为其中一个角色，不单独设计助理专属授权机制。该方向替换 ADR 0001 的分组只读查看功能，业务分组及调用权限保持原有语义，旧查看者的身份迁移另行处理。相较只增加固定助理，这需要角色管理和用户角色绑定，但能让多人共享一套权限并支持其他职责；每人关联一个角色，只有内置管理员的登录会话可管理和分配角色。助理以默认模板预置，可继续编辑；角色状态和权限在后续请求重新读取。完整边界、迁移和回滚见 `docs/admin-permissions-design.md`。
